# Promo copy: titles and descriptions

Separate from the clips — nothing here is burned into the video. Paste as is.

One clip per section, named to match the file in the `promo-clips` artifact
(`<scene>-wide.mp4` for YouTube and X, `<scene>-tall.mp4` for TikTok, Reels
and Shorts).

## How these are written

Search on YouTube and TikTok both read the title and the caption, so every
title leads with the words someone would actually type, not with the brand.
"Dynasty trade calculator" is a search; "StreakPros is great" is not. The
brand goes at the end, after the hook has done its job.

- **YouTube / Shorts title** — under 60 characters so it is not truncated on
  mobile. Keyword first, then the payoff.
- **TikTok / Reels caption** — under 150 characters. TikTok indexes caption
  text now, so the keyword has to be in the words, not only the hashtags.
- **Description** — the first 150 characters are what search shows and what
  the viewer sees before "more", so the keyword and the link go there. The
  rest is for context.
- **Hashtags** — three to five. More than that reads as spam and dilutes each
  one.

Primary keywords worth owning, roughly in order of how much traffic they
carry against how hard they are: `fantasy football`, `dynasty rankings`,
`dynasty trade calculator`, `start or sit`, `waiver wire pickups`,
`fantasy football app`, `sleeper league`, `nfl live scores`, `player props`,
`hit rate`.

Standing description tail to append to every YouTube post:

> Free at https://streakpros.com — no paywall to look around, sync as many
> leagues as you like with just an account.

## Things worth doing that are not copy

- **Post the vertical cut to all three** of TikTok, Reels and Shorts. Same
  file, three audiences, no extra work.
- **Put the keyword in the filename** before uploading. `dynasty-trade-
  calculator.mp4` beats `tradecalc-tall.mp4` as a ranking signal, weak as it
  is, and costs nothing.
- **The thumbnail stills** in the artifact (`<scene>-wide.jpg`) are grabbed
  one second in, which is usually mid-card. If one looks wrong as a
  thumbnail, pull a different frame rather than shipping it.
- **Add your own audio.** Every clip ships with a silent track for upload
  compatibility, which is not the same as being watchable. A trending sound
  on TikTok is worth more than anything written above.
- **Say the keyword out loud** if you add a voiceover. Both platforms
  transcribe audio and index it.
